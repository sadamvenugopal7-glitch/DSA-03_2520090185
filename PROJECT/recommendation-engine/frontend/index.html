Engine Architecture & DSA Concepts

Real Data Structures & Algorithms implemented in the backend recommendation core

⚡

Max-Heap Priority Queue

Custom binary heap implemented from scratch. Evaluates candidates and extracts Top-K movie recommendations in optimal O(K log N) time instead of full O(N log N) sorting.

🗺️

HashMaps & Dictionaries

Maintains Genre → Weight and MovieId → Score mappings in O(1) average lookup time to dynamically learn and tune user genre preferences from star rating history.

🛡️

HashSets for Deduplication

Leverages HashSets for O(1) membership testing to filter out already-rated films, prevent duplicate recommendations, and check user favorites instantly.

🎯

Multi-Factor Scoring

Combines Jaccard genre similarity (50%), historical rating affinity (25%), and normalized global critic scores (25%) into a transparent recommendation score out of 10.
